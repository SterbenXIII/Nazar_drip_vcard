# Refactoring Prompt

**Goal:** Refactor [Component/Module Name] to [Improvement Goal]

**Tools:**

- `context7`: To check for deprecations or better patterns.
- `sequentialthinking`: To plan the refactoring steps safely.

**Steps:**

1. **Analyze Current Code:**
   - Read the file(s) to be refactored.
   - Identify dependencies.

2. **Check Documentation:**
   - Use `context7` to look up the relevant library (e.g., Astro, Hono).
   - Check for "best practices" or "breaking changes" related to the code.

3. **Plan Refactor:**
   - Use `sequentialthinking` to plan atomic steps.
   - Ensure backwards compatibility if possible.
   - Plan tests/verification.

4. **Execute:**
   - Make changes in small chunks.
   - Verify after each chunk.

5. **Update Docs:**
   - If the change affects patterns described in `AGENTS.md`, update it.
