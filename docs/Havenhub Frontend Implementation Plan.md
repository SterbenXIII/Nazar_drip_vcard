# B. Окремі продуктово-технічні рішення

Домен HavenHub.com не є підтверджено придбаним; можливий haven-hub.lviv.ua теж не є URL. «Перейти на основний сайт» залишити неінтерактивним до точного HTTPS посилання. SEO має окремі gates: зараз — точна географія та структура при noindex,nofollow; після придбання домену — канонічний HTTPS URL, metadata, sitemap/robots і звірені фактичні локації; перед індексацією — погоджений контент, права на активи, перевірені медичні твердження, security/release review та окреме рішення власника. Не створювати міські сторінки, адреси або schema для неіснуючих локацій.  
Форма бажана з полями ім’я, телефон, тип залежності й доставкою до Telegram-бота/чату. Це окремий B0–B4 план: звірити чинний payload, privacy, адресата, retention, контроль доступу, Turnstile та правила успіху/повторів; змінювати API/shared і вмикати форму лише після явного затвердження контракту. Viber, SMTP і Discord — потенційні наступні адаптери, не вимога поточного MVP. До gate форма disabled, без реальних заявок.  
Готовність до інтеграції цього worktree вирішувати після A6 на підставі фактичного diff, Docker/zoom результатів, суміжних тестів, незалежного review саме кінцевого diff і переліку обмежень. Висновок READY FOR INTEGRATION або BLOCKED із причинами; навіть READY не виконує merge. Готовність до production визначати окремо після контенту, прав на активи, домену, секретів, операційних рішень і release-перевірок. Без staging, commit, push, merge чи deploy в межах цього планового оновлення.
