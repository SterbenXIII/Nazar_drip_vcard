## Робочі метадані

- `/` H1: «Допомога людям із залежностями та їхнім близьким».
- Робочий title: «HAVENHUB — допомога при залежностях, Львівська область». Затвердити після домену й редакційного review; не обіцяє виїзд усією Україною.
- Робочий description: «HAVENHUB — центр у Львівській області. Програма допомоги людям із залежностями та родині. Виїзд у Львові й області. Гаряча лінія 24/7; перша первинна консультація безкоштовна». Перед публікацією перевірити точність і читабельність, не набивати ключами.
- `/programa/`, `/umovy/`, `/rodyni/`, `/napriamy/`: власні title/H1 для людей, `noindex`, без canonical на `/`, без входження до sitemap.
- `lang=uk`; canonical `/` тільки на верифікованому HTTPS домені; OG/Twitter текст відповідає видимому змісту. Не використовувати макетні інтер'єри для social preview.

SEO перевірка включає відсутність глобального `X-Robots-Tag: noindex` на public `/`, доступ crawler до чотирьох noindex URL, sitemap лише з `/`, один H1, HTTP 200/404 та відсутність публічних placeholder текстів. Search Console перевіряти після окремого release.
